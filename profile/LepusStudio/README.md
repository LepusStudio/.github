# 🐇 Lepus Studio

Bem-vindo ao perfil oficial da **Lepus Studio**!

Somos um estúdio fictício de desenvolvimento de jogos criado para o projeto da disciplina de **Programação Orientada a Objetos (POO)**. Nosso objetivo é desenvolver experiências criativas, divertidas e interativas, aplicando na prática os conceitos aprendidos durante a disciplina.

> **Criatividade, programação e diversão em um só projeto.**

---

## 🎮 Quem somos?

A **Lepus Studio** nasceu como uma empresa fictícia voltada para o desenvolvimento de jogos em estilo **2D Pixel Art**. Inspirados por jogos independentes, buscamos criar projetos com identidade própria, humor e mecânicas simples, mas envolventes.

Nosso primeiro projeto é **Infinite Sprint**, um jogo ambientado na nossa escola onde o jogador precisa escapar de situações inesperadas enquanto enfrenta desafios em diferentes salas de aula.

---

## 🚀 Nossa missão

Desenvolver jogos criativos que unam entretenimento e aprendizado, colocando em prática conceitos de programação, organização de projetos e trabalho em equipe.

## 👁️ Nossa visão

Criar experiências divertidas utilizando programação orientada a objetos e explorar diferentes mecânicas de jogos durante o desenvolvimento.
